# Описание

- Проект из веб-приложения «Витрина интернет-магазина» и RESTful-сервиса платежей
- Витрина товаров, карточка товара, корзина, оформление заказа, список заказов
- Кеширование товаров в Redis, получение баланса и оплата через сервис платежей
- Учебный проект 8-го спринта. У каждого покупателя свои корзина, заказы и платёжный счёт

## Стек

- Java 21
- Spring Boot 3.5.5
- Spring WebFlux, Thymeleaf
- Spring Security, OAuth2 Client Credentials, Keycloak
- Spring Data R2DBC
- Spring Data Redis
- H2
- Redis
- OpenAPI Generator
- Maven
- Встроенный Netty
- JUnit 5
- Docker

## Сборка

Из корня проекта с JDK 21 выполните команду для сборки обоих модулей. Вместо `mvn` можно использовать `sh ./mvnw` в Linux и macOS или `.\mvnw.cmd` в PowerShell на Windows.

```
mvn clean package
```

После сборки исполняемые JAR находятся в каталогах модулей.

- `market-app/target/market-app-0.0.1-SNAPSHOT.jar`
- `payment-service/target/payment-service-0.0.1-SNAPSHOT.jar`


## Тесты

```
mvn test
```

- Тесты со Spring-контекстом используют общие базовые классы для повторного использования контекста. Модульные тесты сервисов запускаются без Spring-контекста
- Таблицы и товары создаются скриптами `schema.sql` и `data.sql` при старте контекста, у тестов репозиториев своя база в памяти


## Запуск и использование

Для запуска из JAR поднимите Redis и Keycloak из корня проекта.

```
docker compose up -d redis keycloak
```

После сборки запустите сервис платежей и витрину в двух отдельных терминалах.

```
java -jar payment-service/target/payment-service-0.0.1-SNAPSHOT.jar
```

```
java -jar market-app/target/market-app-0.0.1-SNAPSHOT.jar
```

- Витрина открывается по адресу `http://localhost:8080`, сервис платежей работает на порту 8081, Keycloak на порту 8082
- Гость может просматривать каталог и карточки товаров. Для покупки нажмите «Войти» и введите "buyer1" или "buyer2". У обоих учебных покупателей пароль совпадает с логином.
- Каждый покупатель начинает с 1000 рублей. При нехватке денег или недоступности сервиса платежей в корзине появляется сообщение, кнопка «Купить» блокируется. После перезапуска сервиса платежей балансы сбрасываются
- База данных H2 в памяти, после остановки приложения корзина и заказы не сохраняются
- Таблицы создаются при старте из `market-app/src/main/resources/schema.sql`, товары загружаются из `market-app/src/main/resources/data.sql`, картинки лежат в `market-app/src/main/resources/images`
- Товары кешируются в Redis на 2 минуты


## Запуск в Docker Compose

Чтобы запустить все четыре сервиса в Docker, выполните из корня проекта следующую команду. JAR собираются внутри образов. При первом запуске Keycloak импортирует realm `market` с клиентом `market-app`.

```
docker compose up --build -d
```

Остановить все контейнеры:

```
docker compose down
```

## Сервис платежей

Витрина получает токен у Keycloak по Client Credentials и передаёт его в заголовке `Authorization: Bearer <token>`.
При запуске из JAR адрес выдачи токена `http://localhost:8082/realms/market/protocol/openid-connect/token`.
Токен подтверждает клиента `market-app` и предназначен для `payment-service`.
Логин покупателя витрина берёт из текущей сессии.


- `GET /balance?username=buyer1` - получить баланс покупателя
- `POST /payments?username=buyer1` с JSON `{"amount": 100}` - списать сумму и получить остаток

Коды ошибок сервиса платежей

- `400` при отсутствии или пустом значении `username`, а также при некорректной сумме платежа
- `401` при отсутствии или недействительности токена
- `403` при обращении другого клиента с действительным токеном для сервиса платежей
- `409` при нехватке денег


## Страницы

Товары:

- `GET /items?search=&sort=NO&pageNumber=1&pageSize=5` - витрина товаров с поиском, сортировкой и пагинацией
- `POST /items?id=&action=` - изменить количество товара в корзине со страницы витрины
- `GET /items/{id}` - страница товара
- `POST /items/{id}?action=` - изменить количество товара в корзине со страницы товара
- `GET /images/{name}` - картинка товара

Корзина:

- `GET /cart/items` - корзина
- `POST /cart/items?id=&action=` - изменить количество товара или удалить его из корзины

Заказы:

- `POST /buy` - оформить заказ из корзины
- `GET /orders` - список заказов
- `GET /orders/{id}` - страница заказа
